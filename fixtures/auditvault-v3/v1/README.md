# auditvault-v3 fixture v1

Normative test vectors for AuditVault v3 (`docs/design/AUDITVAULT_V3.md` §5, §3, §11.4).
They are generated by implementations that share no code with the Solidity contract, and the
contract is checked against them in `test/AuditVaultV3Fixtures.t.sol`.

| File | Contents | Generator |
|---|---|---|
| `rfc6962.json` | RFC 6962 SHA-256 Merkle trees: leaves, root, every inclusion proof and every internal node (with its path to the root) for n = 1…17; the n = 1000 root with sample proofs; the EVIDENCE_SCHEMA §1.2 single-leaf root | `gen/gen_rfc6962.py`: Python standard library (`hashlib`), recursive MTH / PATH from RFC 6962 §2.1 / §2.1.1 |
| `eip712.json` | EIP-712 vector for one `Batch`: type hashes, domain, domain separator, structHash, batchHash (the full digest) and an ECDSA signature by anvil account #0 | `gen/gen_eip712.ts`: ethers v6 `TypedDataEncoder` + `SigningKey` (RFC 6979 deterministic) |

## Conventions

- **Leaf hash** `sha256(0x00 ‖ action_ref)`, **node hash** `sha256(0x01 ‖ left ‖ right)`, split at the largest power of two `< n`, ordered pairs (design doc §5.1).
- **Proofs** are listed leaf to root (RFC 6962 §2.1.1 `PATH`). They are verified with `(leaf_index, tree_size = leafCount, path)` as in RFC 9162 §2.1.3.2.
- **Small trees** use leaves `L_i = bytes([i]) * 32` for i = 1…n, matching the informative §5.2 table: n = 1, 2, 3, 4, 5 and 7 give the same roots. The n = 1000 tree uses `leaf_i = sha256(uint32_be(i))`.
- **`nodes[]`** lists each internal node `D[start:end]` and its path to the root, for the node-as-leaf tests (KI-2).
- **EIP-712:** domain `AgentAudit AuditVault` / `3`, chain id 8453. `verifyingContract` is the first CREATE address of anvil account #0; it is a fixed input, not a deployment. `identityRegistry` is the canonical ERC-8004 IdentityRegistry `0x8004A169…a432`, `agentId` 1, `seq` 0, `root` = the n = 3 root. `metaHash = sha256(utf8("auditvault-v3 fixture v1 batch 0"))`.
- The private key in `eip712.json` is the public anvil/hardhat test key. Never use it for funds.

## Regenerate / check

```bash
python3 fixtures/auditvault-v3/v1/gen/gen_rfc6962.py --check
npx ts-node --transpile-only fixtures/auditvault-v3/v1/gen/gen_eip712.ts --check
```

Without `--check`, each script rewrites its file. That is only allowed before v1 is published.

## Versioning

Once merged, v1 is never edited. New vectors go into a new version directory. The planned
3-batch chain with a gap and the equivocating pair go into `fixtures/auditvault-v3/v2/`.
